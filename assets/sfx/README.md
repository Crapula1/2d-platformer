# SFX overrides

Drop `.ogg` files here with these names to replace the built-in synthesized sounds:

- `jump.ogg`
- `double_jump.ogg`
- `attack.ogg`, `attack2.ogg`, `attack3.ogg`  (combo stages 1/2/3)
- `shoot.ogg`  (rifle)
- `shotgun.ogg`
- `hurt.ogg`
- `die.ogg`
- `pickup.ogg`

The override is detected at startup by `scripts/Sfx.gd`. No code changes needed.
